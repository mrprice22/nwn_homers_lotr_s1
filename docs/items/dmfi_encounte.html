Warning: this item is Cursed. If a player acquires this item, it cannot be unequipped, dropped, or sold.

New Feature: Make custom encounters that you can change dynamically in game and call with this wand. See the in game directions in the new DMFI custom encounter area and the tips readme for further information. The Encounter Wand allows you to quickly create and replicate (with the Encounter Ditto Widget) various encounters. Target a location with the wand. The conversation will pop up showing 9 encounter groups. After selecting a group, select one of 9 "types" of encounters. The encounters are ranked from easiest as the top number 1 option to the hardest number 9 option. By Hahnsoo (hahns_shin@hotmail.com
